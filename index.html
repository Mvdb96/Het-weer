Koppeling met GitHub

De meldingen komen van GitHub. Met deze koppeling stuurt de app je instellingen daarheen. De sleutel blijft alleen op dit apparaat.

Hoe maak ik een sleutel?
  1. Ga op GitHub naar Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Kies bij Repository access Only select repositories en selecteer je repository (vorstwacht).
  3. Zet bij Permissions Contents op Read and write en Actions op Read and write.
  4. Kies een vervaldatum, maak de sleutel aan en plak hem hierboven.
